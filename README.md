# homebrew-tap

Homebrew tap for [**nem**](https://github.com/Dieg0Code/nem) — git-style versioned
memory for AI coding agents. Your agent's history already lives on your disk; nem
turns it into versioned, recallable memory shared across Claude Code, Codex and
Antigravity.

```bash
brew install Dieg0Code/homebrew-tap/nem
```

See the [main repository](https://github.com/Dieg0Code/nem) for what nem is and
how your agent uses it.
